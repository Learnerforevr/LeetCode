## 🧠 Approach to Every Problem

My goal is not just to find an accepted solution, but to understand why it works and when the same approach can be applied elsewhere.

Where applicable, solutions will document:

1. **Problem statement:** The problem being solved.
2. **Approach:** The reasoning behind the chosen algorithm.
3. **Algorithmic pattern:** The underlying technique, such as Hashing, Two Pointers, Sliding Window, BFS, DFS, or Dynamic Programming.
4. **Time complexity:** How the running time scales with input size.
5. **Space complexity:** How much additional memory is required.
6. **Edge cases:** Important boundary conditions and potential pitfalls.

Solutions will aim to be readable, efficient, and aligned with the required LeetCode method signature.
